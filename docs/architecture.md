# Архитектура

Streamlit UI → расчётный слой `engine.py` → слой данных `database.py` → SQLite.

Основные сущности: pickup_points (Anchor/обычные ПВЗ), products (SKU), inventory (остаток/резерв/в пути), orders (заказ/статус/маршрут), assumptions (реестр допущений — расширяется).

Расчётная логика отделена от интерфейса. SQLite предназначена для локального MVP; для постоянной облачной эксплуатации потребуется устойчивое внешнее хранилище.
