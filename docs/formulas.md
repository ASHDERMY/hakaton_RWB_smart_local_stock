# Формулы и правила

## Доступный остаток
`I_available = I + I_in - I_res`

## Целевой остаток
`I_target = D × L + SS`

## Потребность в пополнении
`Q = max(0, I_target - I_available)`

## Предварительная оценка Mesh на заказ
`C_Mesh/order = C_trip / q_plan + C_variable`

где q_plan — плановая загрузка партии. В текущем интерфейсе это приближение для предварительного назначения маршрута. Для рейсовой модели нужно суммировать объём и количество всех заказов в партии.

## Hub
`C_Hub = c_Hub × quantity`

c_Hub — редактируемая сравнительная гипотеза, пока не подтверждённая внутренняя себестоимость RWB.

## Правило выбора
Mesh назначается, если:
1. Есть доступный запас в Anchor.
2. ПВЗ назначения является обычным активным ПВЗ.
3. Количество и объём укладываются в ограничения.
4. Оценка Mesh ниже оценки Hub.

Иначе выбирается Hub при наличии запаса на Hub. Если товара нет ни там, ни там, заказ не создаётся.

## Ограничения
Текущая финансовая сводка показывает оценочные затраты созданных заказов. Хранение, пополнение, стоимость капитала в запасе, возвратная логистика, потери, вознаграждение ПВЗ и маржинальный эффект продавца/покупателя пока не включены в полную стоимость.
