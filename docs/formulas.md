# Формулы

Доступный запас: `I_available = I + I_in - I_res`

Целевой запас: `I_target = D × L + SS`

Пополнение: `Q_replenishment = max(0, I_target - I_available)`

Локальная стоимость на заказ: `C_trip/order = C_trip / q`

Упрощённая стоимость Mesh: `C_Mesh = C_trip/q + C_variable`

Mesh выбирается, только если товар доступен, SLA соблюдается, лимиты количества и объёма не превышены и полная сопоставимая стоимость Mesh ниже Hub. Иначе используется Hub.

Полная модель должна учитывать пополнение и хранение по SKU и Anchor, распределяя стоимость запасов на фактически реализованные товары, а не списывая весь запас на продажи периода.
