# Smart Local Stock

Рабочий учебный MVP для моделирования локального хранения товаров в Anchor-ПВЗ и выбора логистического маршрута Hub/Mesh.

## Запуск
```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

При первом запуске схема SQLite создаётся автоматически. Для тестового набора нажмите «Загрузить демонстрационные данные».

## Реализовано
- Каталог SKU и сеть точек (Anchor, обычные ПВЗ, Hub).
- Приёмка товара и журнал движений запасов.
- Создание заказа с проверкой остатков, резервированием и предварительным выбором Hub/Mesh.
- Управление статусами заказа: зарезервирован → в пути → готов к выдаче → выдан; отмена и фиксация ошибки.
- Регистрация возврата, проверка состояния и возврат пригодного товара в запас.
- Регистрация логистических инцидентов.
- Расчётная финансовая сводка по заказам.

## Важные ограничения модели
Выбор маршрута для отдельного заказа использует плановую загрузку партии как приближение. Реальная стоимость рейса должна рассчитываться по сгруппированной партии заказов с проверкой общей вместимости и маршрута. Возврат оформляется после выдачи; частичные возвраты учитываются отдельной записью. Полная экономика хранения, пополнения, потерь и начислений ПВЗ — следующий этап.

## Данные и гипотезы
Параметры стоимости рейса, Hub и переменных расходов редактируются в приложении и помечаются статусом. Публичный тариф продавца нельзя подменять внутренней себестоимостью логистики маркетплейса. См. `docs/assumptions.md`.

## Публикация
Для Streamlit Community Cloud укажите `app.py` как основной файл. Локальная SQLite-база не является надёжным постоянным хранилищем в облачной среде; для реального публичного использования потребуется внешняя постоянная БД. Текущий выбранный SQLite сохраняется для локальной разработки и защиты MVP.
