# Smart Local Stock

MVP системы локального хранения востребованных товаров и выбора маршрута Hub/Mesh.

## Стек
Python · Streamlit · SQLite · pandas

## Запуск (Windows)
```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```
При первом запуске создаётся SQLite-база. Нажмите «Загрузить демоданные» в боковой панели.

## Логика
Mesh — локальное перемещение от опорного ПВЗ Anchor к обычным ПВЗ. Оно допустимо при наличии товара, соблюдении SLA и ограничений рейса, а также при меньшей сопоставимой стоимости. В остальных случаях используется Hub.

## Гипотезы
2 400 ₽/рейс; лимит 130 заказов; 1 500 л; 4 л/заказ; ожидание до 5 часов; Hub 62 ₽/заказ; Smart 10 000 ₽/период. Это не подтверждённые тарифы и не внутренняя себестоимость RWB. Подробности — `docs/assumptions.md`.

## Публикация
Подключить репозиторий к Streamlit Community Cloud, Main file path: `app.py`. Локальный SQLite-файл в облачной файловой системе не следует считать постоянным хранилищем; для промышленной эксплуатации потребуется внешняя БД. SQLite оставлен для локального MVP согласно выбранной архитектуре.

## Статус
Первая версия каркаса и демонстрационного калькулятора. Полный учёт пополнения, хранения, возвратов, начислений участников и подтверждённая экономика будут добавлены отдельными этапами.
